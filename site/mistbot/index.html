Mist Bot

A farming bot for Mist World. It walks your character to the farming map, fights, drinks potions, looks after your pets, sorts your bag, does your daily chores, and goes home when you tell it to.

Download Mist Bot from its latest release on GitHub

Opens the latest release on GitHub. Mist Bot is a modified version of Uncle Farmer; the program still calls itself Uncle Farmer.

What it does

Plans and scripts

Pick maps, how long to farm each one, how to move around and which monsters to fight. Stop after a time, at a clock time, after a number of kills, or when an item runs low. Scripts, with loops and conditions, cover what a plan can't.

Fighting

It scans each character itself: class, skills on every key, talents, combos, potions, beasts and pets. Each class fights from its own attack's distance and picks skills by cooldown, rage, marks and combos.

The bag

Every shard and item goes to Throw away, Keep, Store or Sell. It refills potions and food from the storehouse or the shop, and unloads or stops when the bag is full or the day's drop time runs out.

Chores and tools

Daily chores once a game day: bank income, bounties, pet rebirths, gang donation and construction. Gem Maker, Equipment Enhancer, gathering and dungeons, none of them spending below your arnebia reserve.

Travel

Between any two of the game's 375 maps, by cable car and airship, or a walk to a map or dungeon entrance. It keeps off lava and crosses Polson Wetland on a fusion beast.

AI assistants

An assistant that supports MCP, such as Claude, can run the bot for you: start and stop plans, run the jobs, read the log and results, change settings. It is off until you turn it on in Settings, Control.

Results

Kills, contribution, experience, arnebia, shards, skills used and healing, for a run, any day, the last week or month, or all time. Shift+Pause speaks a one-line summary.

Getting started

You need Windows, Mist World, and NVDA set as the game's default speech. Important events are spoken through NVDA.

  1. From the latest release on GitHub, download MistBot-<version>.zip and unpack it where you want the bot to live. It holds UncleFarmer.exe in a Mist Bot folder; your settings, plans and results are kept in that folder.
  2. Run UncleFarmer.exe. The first time, it opens Settings: choose your Mist World folder, or start the game and press Find the running game, then press Install.
  3. Restart Mist World and log in. Make a plan in the Plans tab, then press Start on the Bot tab.

Install adds one line to the game's mw.exe.vmoptions and keeps the original as a backup. Remove, in the same place, takes the line out again.

New versions: the bot offers them when it starts, every 6 hours while it's open, or from Help, Check for updates, and installs them itself. Releases are signed, and it only installs one whose signature checks. The release also has UncleFarmer.exe on its own, for replacing an older copy by hand.

Privacy

  • There's no account, no server, no licence check and no telemetry.
  • The update check asks GitHub for the latest release and carries nothing about you or your game. Untick it in Settings, Updater and the bot never goes online.
  • Settings, plans, scripts, logs and results are plain files in the bot's folder.
  • The agent inside the game listens on 127.0.0.1 only, with a secret it makes up at each launch. It doesn't write chat or network packets to disk.
